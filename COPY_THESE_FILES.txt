Why v0.2.4:
- Gemini video analysis runs with Interactions Background Execution.
- The long server job gets an Interaction ID and is polled every 5 seconds.
- If a poll connection resets, the same server-side task continues.
- Analysis is bounded to 240 seconds per model in GitHub Cloud.
- Fallback remains: 3.7 Flash -> 3.6 Flash -> 3.5 Flash.
- transcript.json is saved immediately after successful analysis.
- If TTS later fails, process attempt 2 reuses the transcript checkpoint.
- Whole-process attempts reduced from 3 to 2.
- TTS retry ceiling reduced to 4 in GitHub Cloud.
- Workflow timeout reduced to 45 minutes.
- Partial checkpoint output is uploaded on failure when available.
