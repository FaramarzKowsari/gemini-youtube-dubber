Gemini YouTube Dubber v0.2.1 Hybrid Cloud Patch

Files in this patch:
- dubber/cloud_pipeline.py       NEW
- cloud_cli.py                   NEW
- finalize_cloud_dub.py          NEW
- FINALIZE_CLOUD_DUB_WINDOWS.bat NEW
- .github/workflows/cloud-dub.yml REPLACE

WHY:
GitHub-hosted runners are often blocked by YouTube with:
"Sign in to confirm you're not a bot".

NEW FLOW:
1) GitHub Actions sends the public YouTube URL directly to Gemini.
2) GitHub generates translated dub audio, SRT and transcript.
3) Download the resulting cloud-dub-package ZIP artifact.
4) On Windows run FINALIZE_CLOUD_DUB_WINDOWS.bat.
5) The source video is downloaded locally and merged with the cloud-generated dub.

INSTALL:
Extract this ZIP directly into your cloned repository root:
C:\Faramarz\GitHub\gemini-youtube-dubber-github

Choose Replace when Windows asks about:
.github\workflows\cloud-dub.yml
